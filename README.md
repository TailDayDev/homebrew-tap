# TailDay Homebrew Tap

## YouTrack CLI (`yt`)

```bash
brew tap TailDayDev/tap
brew install yt
```

Or in one command:

```bash
brew install TailDayDev/tap/yt
```

## Admin dictionary CLI (`red-sky`)

```bash
brew tap TailDayDev/tap
brew install red-sky-cli
```

Or in one command:

```bash
brew install TailDayDev/tap/red-sky-cli
```
